# Students Compaint and Issue Tracking System

Create a full-stack Student Complaint and Issue Tracking System using
React (frontend), Node.js + Express (backend), MongoDB (database).
Features:
	•	Student & Admin authentication (JWT)
	•	Submit complaints with category and description
	•	Track complaint status (Pending, In Review, Resolved)
	•	Admin dashboard to respond and update status
	•	Clean folder structure and comments in code”
